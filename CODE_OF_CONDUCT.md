# Code of Conduct

## Our standard

We want collaboration here to be technically rigorous, welcoming, and safe. Contributors are
expected to:

- discuss ideas and code without personal attacks or harassment;
- give specific, evidence-based feedback and accept correction gracefully;
- respect privacy, consent, and the security boundaries of other people's systems;
- avoid publishing private prompts, credentials, logs, or vulnerability details;
- make space for contributors with different experience levels and backgrounds.

Unacceptable behavior includes harassment, discrimination, threats, deliberate disruption,
doxxing, sexualized conduct, and sustained bad-faith interaction.

## Scope and enforcement

This policy applies in project repositories, reviews, issues, discussions, and project-related
public spaces. Maintainers may edit or remove contributions, restrict participation, or ban people
whose behavior violates this policy. Enforcement decisions should be proportionate, documented,
and protect reporters' privacy.

Report conduct concerns privately to the maintainers. After the GitHub repository is published,
use its private **Security → Report a vulnerability** channel and identify the report as a conduct
matter. Do not open a public issue containing sensitive personal information.
